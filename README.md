## 🚀 Featured Projects

### 1. LRT2042 Access Control System (`pic18-access-control`)
* **Domain:** Embedded Systems / Microcontrollers (MPLAB X / PIC)
* **Description:** A robust microcontroller-based access control firmware developed using MPLAB X IDE and Microchip Harmony components. Handles credential validation, secure logging, and peripheral interfacing.
* **Tech Stack:** C, MPLAB X, Microchip PIC, MCC (Microchip Code Configurator).

### 2. Solar Energy Monitoring System (`pic18-solar-tracker`)
* **Domain:** Embedded Systems & Renewable Energy
* **Description:** Real-time solar panel performance and metrics monitor with dedicated LCD display drivers and sensor polling. Designed for efficiency and reliability in off-grid environments.
* **Tech Stack:** C, MPLAB X, Embedded C, LCD Interfacing.

### 3. STS3215 Bus Servo ID Setup Utility (`servo_id_setup`)
* **Domain:** Robotics & Hardware Tooling
* **Description:** A streamlined ESP32-based configuration tool for Waveshare / STS3215 serial bus servos. Allows quick serial scanning, single-servo ID assignment, and diagnostic test movements without complex desktop software.
* **Tech Stack:** C++, Arduino, ESP32, SCServo Library, UART.

### 4. FreeLLMAPI Self-Hosted Gateway (`freellmapi`)
* **Domain:** AI Infrastructure & Backend Services
* **Description:** A secure, containerized local API proxy/gateway for managing LLM provider keys with at-rest encryption and health checks.
* **Tech Stack:** Docker, Node.js, Docker Compose, REST APIs.
